| Key | zh heading | ja heading |

| **`talk`** (new) | 【小G的话】 | 【ジーくんのことば】 |
| `summary` | 【小结】 | 【まとめ】 |
| `checkQ` / `checkA` | 【试试】 split at 「答案：」 | 【たしかめよう】 split at 「こたえ：」 |

- RAG has no `talk` key. In this course, 小G的话 carries the explanation (and several honesty caveats), so it must be shown: in the tutor bubble or as a phase.
- Two parser quirks seen in the current RAG output that the new builder must avoid: `vo` strings end with `"\n\n---"`, and `art` is truncated.
- Page headers: `## 第 N 页　…` (zh) and `## Nページ　…` (ja). Intro: `## 导入` / `## はじめに`. Summary: `## 第 N 章 小结` / `## 第N章の まとめ`. Review: `## ふりかえろう ⭐`. Ignore `|` table rows (maker tables) and `>` lines.
- **Numbers rule:** picture numbers must come from `results.json` through a generated `src/data/embed-facts.js`, never typed by hand. The builder should port `embed-script/verify.py` and `verify_pairs.py`: it fails if a page shows a 分/てん number missing from the facts, contains "→", a decimal or a negative, or (ja only) quotes 45, 71, 74 or 83てん.
- Kids see integers only: `points = round(cos×100)`.

## 2. zh vs ja

- **zh:** Chinese word set (`words.zh`) and Chinese cards. RAG links use `rag:` numbers; this is valid because it is the same model.
- **ja:** English word set (`words.en`), shown on cards as **日本語 big + English small**, e.g. 朝ごはん〔breakfast〕. The gloss table is `ja_gloss` in `demo/embed_demo.py`. The model reads only the English. The Japanese words that are fed in as-is are the cross-language pairs (`pairs.cross_language`: 朝ごはん, 犬, いぬ, 猫, ねこ, 駐車場, ちゅうしゃじょう, プール).
- **ja rule (user decision):** no RAG-book scores and no "second number-maker". Every ja number comes from `results.json`. RAG is referred to only qualitatively. In c3-p5 and c5-p4 the strip is made differently from the RAG book's, measuring by angle is the same, and "1st place is the same" is only claimed for that question.
- The page count and order are identical; only the numbers differ.
