# nanoGPT 闯关

用 [Phaser 3](https://phaser.io/) 做的点击推进小游戏，把语言模型讲成非程序员也能跟上的微步骤。

依据 [karpathy/nanoGPT](https://github.com/karpathy/nanoGPT) 的 `shakespeare_char` 事实，按 31 拍讲完第 1–5 章。每一拍是一页课本，不是一句口号，固定五块：

1. **干什么**
2. **为什么**
3. **完整小例子**（真字符→号码、x/y 对齐、65 格只点亮真答案）
4. **常见误会**
5. **一句话记住**

关内用「下一页」翻这五块；翻完才到下一课。宽屏上 Live2D 助教叠在视口右侧，不占课程宽度；完整五块笔记用「详细笔记」打开。当前这一课的短伪代码用「伪代码」打开：干什么、对应纸带、几行可读伪代码、一句误会。

顺序是：纸带 → 号码牌 → 座位号 → 65 → 练习/验收 → 随机剪段 → x → y 右移 → 填空 → 65 候选 → 评分桌 → 猜错罚分 → 平均分 → 回头看左边 → 提问/标签/内容 → 因果遮罩 → 一份重量 → 加权汇总 → 加回这一格 → 乱猜为什么要开训 → 一批窗口改一笔 → 改哪些数 → 验收卷抽查 → 官方启动命令 → 怎样算讲完 → 从开头续字 → 一格一格接上 → 温度和前几名 → 官方采样命令 → 采样不是正确率 → 五步走到这里。

**本游戏不训练模型，也不编造 loss、注意力小数或采样台词。** 源码名只作为可选脚注。演示短句仍是 `Second Citizen:\n`。第 1 章 5 拍、第 2 章 8 拍、第 3 章 6 拍、第 4 章 6 拍、第 5 章 6 拍，顶栏步数连成 1/31，细节是 1/5。标题页可以选择五章，学过的章可以再进。关内「返回」回到上一块，「目录」随时重选。第一次进来会先看一页导读。右上角可以切中文 / 日本語，配音跟着变。第 4 章结束进入第 5 章，第 5 章结束才到通关。

## 本地运行

需要 Node.js 18+。

```bash
cd game
npm install
npm run dev
```

浏览器打开终端里的本地地址（默认 `http://localhost:5173`）。

点击「开始」，再按「下一页」翻完五块，或点空白处 / 按空格推进。五块标签也可直接点。

顶上的喇叭是 **DOM 按钮**：先立刻翻转图标并写入 `localStorage` 键 `nanogpt-game-muted`，再在下一课才碰 BGM / 配音。不会在点击当帧重启整套音频。浏览器会拦截自动播放：第一次点「开始」或喇叭后才会解锁 Web Audio。

旁边「看不懂？」打开词语小抄：BPE、号码牌、练习卷/验收卷、右移一格、猜错罚分，以及注意力、提问/标签/内容、因果遮罩、一份重量、开训、采样。「伪代码」跟着当前这一课变，不把代码铺在画布上。「详细笔记」在游戏区内打开，不盖住助教的脸。电脑端还有游戏指针，会跟着悬停和点击变样子。

## 构建

```bash
cd game
npm install
npm run build
```

静态文件在 `dist/`。可用 `npm run preview` 预览生产构建。

## 宽屏 Live2D 助教

CSS 宽度 ≥ 1024 且横屏、并且不是手机 UA 时，Live2D 助教（桃瀬ひより）叠在整页羊皮纸上，背景透明，不被窄列裁切。她在画面最上层的角色层，静音和笔记按钮仍在她之上、并且不压住额头。口型跟着配音，眼睛和头跟着鼠标，点在她身上会做反应。启动时只创建一个 Pixi / Live2D 实例。

手机 / 竖屏 **完全不加载** Pixi、Cubism Core 和模型，避免拖慢。

模型与授权见 [`public/assets/live2d/LICENSE.md`](public/assets/live2d/LICENSE.md)。Cubism Core 从 Live2D 官方 CDN 加载，不进仓库。

## 音频

| 资源 | 内容 | 何时播放 |
|------|------|----------|
| `public/audio/bgm.{ogg,mp3}` | 循环轻音乐（C 大调 4 小节） | 解锁后循环，音量低于配音 |
| `vo-title` | 「从一条长纸带讲起。」 | 标题页 |
| `vo-level1` | 「每个字符领一张号码牌。」 | 领号码牌 |
| `vo-map` | 「号码只是座位号。」 | 不是性格 |
| `vo-reuse` | 「本局只有六十五张字符牌。」 | 65 张牌 |
| `vo-level2` | 「每次随手剪一段来看。」 | 随机剪段 |
| `vo-shift` | 「答案往右挪一格。」 | y 右移 |
| `vo-next` | 「每个位置都在问下一字。」 | 一串填空 |
| `vo-loss` | 「押得越少，错题分越大。」 | 真答案的概率 |
| `vo-clear` | 「通关啦！」 | 结算页 |
| `sfx-tap` / `sfx-pop` | 轻点按、揭示音 | 按钮 / 空白点击、id 徽章落下 |

音乐和音效是仓库内用 NumPy 合成的**原创**素材（按 CC0 使用即可），不是商业曲或游戏 OST。原先几句中文配音用 Microsoft Edge 在线 TTS（`zh-CN-XiaoxiaoNeural`）；若环境没有 `edge-tts`，脚本会退回 `espeak-ng` / `espeak` 的中文朗读。每一课的核心一句，以及打开「伪代码」时的一句，会再走浏览器的 Web Speech：中文用 `zh-CN`，日本語用 `ja-JP`。有现成中文片段时仍播片段；没有片段、或当前是日本語时，念这一课的句子。静音会同时停掉片段和朗读。

重新生成（需要 `python3`、`numpy`、`ffmpeg`，以及 `edge-tts` 或 `espeak-ng`）：

```bash
pip install edge-tts
python3 game/scripts/generate-audio.py
```

脚本把 44.1 kHz 单声道写成 80 kbps MP3 + Vorbis q3 OGG，方便 GitHub Pages 手机端。

## 技术

- Phaser 3（npm）：关卡画布，Retina DPR，header / content / footer 不重叠
- 右上角静音：HTML 按钮，不走 Phaser 点击栈
- 宽屏助教：PixiJS + `pixi-live2d-display`（仅电脑宽屏按需加载）
- Vite + 原生 JavaScript
- 无后端，纯前端
